# Mikä on workflow?

Workflow on **deterministinen prosessi**, joka ohjaa tehtävää läpi sen vaiheet. Jokainen workflow koostuu yhteisistä vaiheista: `Analyze → Plan → Implement → Test → Review → Document`.

## Esimerkki: Feature-workflow

| Vaihe | Vastuu |
| --- | --- |
| Analyze | Researcher |
| Plan | Architect, Planner |
| Implement | Developer |
| Test | Tester, QA |
| Review | Reviewer, Security |
| Document | Documentation |
