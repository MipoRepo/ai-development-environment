# Agenttikerros

Agenttikerros on AIDE:n sydän. Se koostuu rooleista, jotka on jaettu selkeisiin kokonaisuuksiin:

- Orchestration (Director, Project Manager)
- Planning (Planner, Requirements)
- Development (Developer, Reviewer)
- Testing (Tester, QA)
- Security (Security Architect, SAST)
- Documentation (Writer, API Docs)
- DevOps (Docker, CI/CD)
- AI / Model (Model Router, Registri)

---

## Moduulit

| Moduuli | Nimi | Vastuu |
| --- | --- | --- |
| M1 | Core & Director | Agenttijärjestelmän ydin |
| M2 | Project Management | Projektin luonti ja hallinta |
| M3–M7 | ... | Analyysi, kehitys, testaus, turvallisuus, dokumentaatio |
| M8–M20 | ... | Käyttöliittymä, DevOps, AI-infra, itsekehitys |
