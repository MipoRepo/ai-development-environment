# Vanha TODO (Arkistoitu)

Tämä kansio sisältää **arkistoituja** TODO-listoja, jotka liittyvät projektin aikaisempiin vaiheisiin.

## Sisällysluettelo
- `TODO.md` — Alkuperäinen 24-tehtävän lista, joka kattaa kaikki moduulit M1–M20. Tämä on **arkistoitu versio**, jota ei enää ylläpidetä aktiivisesti.

## Miksi arkistoitu?
Tämä lista on jaettu **moduulitasoiseen** ja **vaiheittaiseen** TODO:ksi, joka sijaitsee `.project-management/todo/TODO.md`-tiedostossa. Arkistoitu lista säilytetään tässä historian ja viittaustarkoituksen vuoksi.

## Miksi tämä on tärkeä?
Käytetty TODO-lista toimii **projektin käynnistys- ja jatkokehittelyohjeena**. Kun olet valmis siirtymään seuraavaan vaiheeseen, kopioi "Seuraavan vaiheen käynnistys"-lohko uuteen TODO:ksi.
